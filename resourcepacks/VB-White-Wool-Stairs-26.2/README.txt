WHITE WOOL STAIRS - EAGLER 26.2 TEST

This test targets the block that ViaBackwards 5.12.0 currently maps
26.3 white_wool_stairs to: quartz_stairs.

IMPORTANT:
This intentionally makes normal Quartz Stairs look like White Wool.
It is only a diagnostic test. It does not change ViaBackwards mappings
and cannot distinguish Quartz Stairs from translated White Wool Stairs.

The folder can be downloaded from GitHub and zipped as the resource-pack
root (pack.mcmeta must be at the ZIP root).
